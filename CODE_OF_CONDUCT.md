# Code of conduct

Be respectful and constructive when participating in this project. Welcome contributors with different backgrounds and experience. Discuss ideas and code without personal attacks. Respect people's privacy and boundaries.

Harassment, threats, discriminatory language, unwanted sexual attention, and publishing someone's private information are not acceptable in issues, pull requests, reviews or other project spaces.

Maintainers may remove inappropriate contributions and restrict participation. They should explain moderation decisions privately where appropriate and apply these expectations consistently.

Report concerns privately through the contact options at [Ambitious](https://ambitiousbots.com). Include enough context to review the concern and avoid posting private details publicly. A maintainer involved in a concern should not be its sole reviewer.
